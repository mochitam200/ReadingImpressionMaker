## 3. テスト実行環境・方法

### 3.1 実行方法

GoogleTest等の外部フレームワークは非依存とし、`main.cpp` 内で各テストメソッドを順次呼び出します。

1. **ビルド**: テスト用ソースコード群（`main.cpp`, 各テストユニットコード）をコンパイルします。
2. **実行**: 出力されたバイナリを実行します。
3. **判定**:
* 各テスト項目について成功時は `[PASS]`、失敗時は `[FAIL]` が標準出力に表示されます。
* プログラム全体の終了コードが `0` であれば全テスト合格、`1` の場合は失敗項目が存在します。
