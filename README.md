# 読書感想文メーカー (ReadingImpressionMaker)

読んだ本の感想を、質問に答えながら整理できる、コンソール形式の読書感想作成アプリです。

---

## 📌 プロジェクト概要

本プロジェクトは、「感想文を書きたいけど、何から書けばいいかわからない」という悩みを解決するためのC++学習用アプリケーションです。
最初に本のジャンルを選択すると、そのジャンルに合った質問が順番に表示されます。質問に答えていくだけで、感想文の材料を自然に引き出せるように設計しています。

### 作成目的

* 読書感想文の作成を、質問への回答という形でサポートすること
* C++を用いたコンソールアプリケーション開発、ファイルI/O（CSVパース）、クラス設計の実践

---

## ✨ 主な機能（Features）

- 📚 **ジャンル別質問出題**: 小説・物語／実用書／ビジネス・自己啓発／専門書・学習書／ノンフィクション・伝記の5ジャンルから選択し、ジャンルに合った質問を表示
- 📂 **CSVデータ動的読み込み**: 質問データをプロジェクト直下の外部CSVファイル `book_review_questions.csv` から読み込み（`CsvLoader`）
- 💬 **対話形式のコンソールUI**: 画面の案内に沿って入力していくだけのシンプルな操作（`ConsoleUI`）
- 💾 **回答のエクスポート**: 回答を終えた内容は `output` フォルダにファイルとして出力され、あとから見返せるように保存（`RecordExporter`）
- ⚠️ **入力バリデーション**: ジャンル選択などで無効な入力に対するエラーハンドリングを実装
- ✅ **単体テスト**: 主要コンポーネントにGoogle Testによる単体テストを用意

### 対応ジャンル

| 番号 | ジャンル | 説明 |
|:---: |:--- |:--- |
| 1 | 小説・物語 | ストーリーや登場人物の心情を楽しむ本 |
| 2 | 実用書 | 日常生活ですぐ使えるノウハウを提供する本 |
| 3 | ビジネス・自己啓発 | ビジネススキルや自己成長を直接扱う本 |
| 4 | 専門書・学習書 | 特定の分野について専門的・学術的に深く追求するための本 |
| 5 | ノンフィクション・伝記 | 事実に基づいた記録や人物の生涯を描いた本 |

## 🚀 セットアップ／インストール手順（Installation）

### 実行ファイルから動かす場合（配布版）

1. リポジトリまたは配布用のアーカイブから `ReadingImpressionMaker` フォルダをダウンロード・解凍します。
2. 質問データのCSVファイルが、実行ファイルから読み込める位置に配置されていることを確認します。

### ソースコードからビルドする場合

1. このリポジトリをクローンまたはダウンロードします。
```bash
git clone https://github.com/mochitam200/ReadingImpressionMaker.git
```
2. Visual Studio で `ReadingImpressionMaker.sln` を開きます。
3. ソリューションエクスプローラーで `ReadingImpressionMaker` を右クリックし、**「スタートアップ プロジェクトに設定」** を選択します。（プロジェクト名が太字になれば設定完了です）
4. プロジェクトのプロパティで、C++言語標準が `ISO C++17 標準 (/std:c++17)`、準拠モードが `はい (/permissive-)` になっていることを確認します。（対象: すべての構成 / すべてのプラットフォーム）
5. ビルド構成を `Release` (または `Debug`) / `x64` に設定します。
6. `Ctrl + Shift + B`（または [ビルド] ➔ [ソリューションのビルド]）を押してビルドを実行します。
7. `F5`（デバッグ付き）または `Ctrl + F5`（デバッグなし）で実行します。

## 🎮 使い方（Usage）

### 1. アプリの起動
* ビルドして実行するか、配布版フォルダ内の実行ファイルをダブルクリックして起動します。

### 2. 感想作成の進行
1. 画面の案内に従って、本の基本情報を入力します。
2. 本のジャンルを聞かれたら、`1` 〜 `5` の番号を入力し、`Enter` を押します。

```text


①小説・物語（ストーリーや登場人物の心情を楽しむ本）
②実用書（日常生活ですぐ使えるノウハウを提供する本）
③ビジネス・自己啓発（ビジネススキルや自己成長を直接扱う本）
④専門書・学習書（特定の分野について専門的・学術的に深く追求するための本）
⑤ノンフィクション・伝記（事実に基づいた記録や人物の生涯を描いた本）

番号を入力してください (1-5)
> 1
```

3. ジャンルに合った質問が順番に表示されるので、それぞれ回答を入力していきます。
4. すべての質問に答えると、回答内容がファイルに出力・保存されます。

### 3. 質問の追加・編集方法
質問データのCSVファイルをメモ帳や Excel 等で編集することで、質問内容を自由に追加・変更できます。
